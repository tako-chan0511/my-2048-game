# STEP 2 実装・検証結果

確認日：2026-11-10（JST）。対象：`~/projects/my-2048-game`。

## 実装

- キー・スワイプ・方向ボタンを共通の`dispatchMove(direction)`へ統合しました。Vue側のガードを通してSTEP 1の`moveGame`を呼びます。旧`move`は同じ関数への別名です。
- キーボードはゲーム領域内でのみ矢印を扱い、入力欄・編集可能領域・修飾キー・IME操作は除外します。ゲーム操作時だけスクロールを抑え、`repeat`キーイベントは移動せず、1押下1手とします。
- スワイプはPointer Eventsとpointer captureを使い、指を離すと1手を確定します。しきい値24 CSS px、主軸がもう一方の1.15倍以上の場合だけ方向を決定します。複数指、pointercancel、capture喪失、window blur、非表示化で取り消します。2本目が盤面外でも取り消し、盤面外の通常スクロールは維持します。
- 他の入力や新しいゲームが始まると、途中のスワイプを破棄します。
- 2048達成時に「2048達成！おめでとう！」、スコア・手数・最大数字、続ける／新しいゲームを表示します。同じゲームで繰り返し表示しません。
- ゲームオーバー時に最終結果、新しいゲーム／盤面を見るを表示します。閉じた後も終了状態を維持し、全入力を拒否します。
- 達成と終了が同時に起きた場合は、達成→ゲームオーバーの順に表示します。
- ポップアップはnative `<dialog>`の`showModal()`を使用し、背景はinertかつスクロール禁止にします。初期フォーカス、Tab／Shift+Tab循環、終了時の盤面へのフォーカス復帰を実装しました。
- Escは達成時の「続ける」、終了時の「盤面を見る」と同じ動作です。背景クリックでは閉じません。
- 静的なタイル、色と数字・テキストを併用した状態表示、48px以上の操作ボタンを維持し、スマートフォンの余白を調整しました。お祝いの記号はフォントに依存しないSVGです。

| 画面 | 盤面幅 | 結果 |
|---|---:|---|
| PC 1366×900 | 420px | キー・ボタン・マウスのスワイプ、長押し、入力欄保護、達成・終了・フォーカス |
| 390×844 | 324px | タッチスワイプ・複数指・キャンセル、盤面外スクロール、達成・継続・フォーカス |

全画面で横方向のはみ出しがなく、最小ボタン高48pxを確認しました。ブラウザのページ例外・コンソールエラーは0件です。ネイティブのinert、背景フォーカス禁止、Tab循環、Esc、閉じた後の盤面フォーカス、入力欄での矢印キーによるカーソル移動を実際に確認しました。

達成・終了直前のケースは、検証時だけブラウザの通信応答内で初期Positionを差し替え、通常のゲームエンジンによる1手で結果を発生させました。テスト専用の盤面設定機能・URLパラメータ・グローバルAPIは製品コードへ追加していません。
