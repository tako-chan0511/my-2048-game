# STEP 5 実装・検証結果

確認日：2026-11-10（JST）。対象：`~/projects/my-2048-game`のみ。

## 実装

- 通常・時間制限・手数制限を実装し、設定編集中と適用済み状態を分離。新しいゲームの採用時だけモードと制限値を適用します。
- 時間制限は10〜3600秒の整数、初期300秒。最初の有効な移動で開始し、無効移動では開始しません。
- 開始・締切・最後に観測した時刻を保存し、残秒の減算ではなく締切との差で残量を求めます。非表示・ページを閉じた間も経過し、復元時の期限切れを判定します。
- 各移動・Undoで時刻を再確認し、締切ちょうど以降の操作を拒否します。Undoで締切を戻さず、時間切れ後はUndo不可です。
- 表示用intervalは最大1本。時間制限の開始後だけ動き、期限切れ・新規開始・モード切替・アンマウント時に解除します。ゴールや手詰まりの表示中も締切は進みます。
- 手数制限は1〜100000手の整数、初期1000手。無効移動は消費せず、最後の有効移動の合体・加点・新規タイルを確定してから終了します。
- 手数上限・手詰まりからは履歴と回数があればUndoで再開できます。使用数・過去の目標達成・通知済みを巻き戻しません。
- 目標と終了を別管理し、重なった場合は達成通知→終了結果。残り制限がなければ「結果を見る」を表示します。終了理由は時間切れ→手数上限→手詰まりを優先します。
- 残り時間・手数、適用モード、終了理由を表示し、残り30秒以下は色と「残りわずか」の両方で警告します。
- 時間切れで開いた結果画面のUndoボタンが消えた場合も、フォーカスを結果画面内へ保ちます。
- 進行保存はversion=2へ更新。旧STEP 4のversion=1を読み込み、同じ保存スロットで移行します。通常モードのベスト比較キーとベストファイルversion=1は維持し、追加モードは秒数・手数上限も比較キーに含めます。

時刻、保存、終了順の詳細は[モード仕様](modes.md)と[保存仕様](persistence.md)に記載しています。
