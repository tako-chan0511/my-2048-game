# STEP 3 実装・検証結果

確認日：2026-11-10（JST）。対象：`~/projects/my-2048-game`のみ。

## 実装内容

- 3×3〜10×10の共通N×Nエンジン、全方向の移動・合体・出現・終了判定。
- 目標128〜65536の10種類、初期1〜N²枚、4の出現率0〜100%。既定の4×4・2048・2枚・10%を維持。
- 「次のゲームの設定」を追加。編集中の値は現在のゲームを変更せず、専用ボタンで検証して成功した場合だけ適用。
- 「新しいゲーム」は適用済みの設定を使用。別の編集中設定や空欄・不正値を混ぜない。
- 入力形式・範囲・整数・初期枚数上限を共通検証し、不正値や開始失敗ではGameState、乱数、スコア、手数、ポップアップを保持。
- 到達不能が証明できる場合だけ事前に警告し、サイズ・目標を変更する提案を表示。警告を踏まえて同じ設定でスコアを目指すことも可能で、設定を勝手に変えない。
- 全マスの初期配置リスクを説明し、開始直後の手詰まりは0手のゲームオーバーとして処理。
- 選択した目標に連動する一度だけの達成ポップアップと、達成後の継続を維持。
- 全サイズをページ幅に収め、セルと表示文字数に基づくフォント調整、指数による略記、位置と正確な値の開閉式一覧を追加。
- 設定適用や結果表示を閉じた後は、操作する盤面が見える位置へフォーカスを戻す。

警告の数学的根拠、設定適用と乱数互換性の詳細は[設定仕様](settings.md)に記載しています。
