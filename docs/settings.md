# 設定仕様（STEP 5）

## 入力と適用

| 項目 | 許可値 | 既定 |
|---|---|---|
| サイズ | 整数3〜10 | 4 |
| 目標 | 128、256、512、1024、2048、4096、8192、16384、32768、65536 | 2048 |
| 初期タイル | 整数1〜N² | 2 |
| 4の出現率 | 整数0〜100% | 10% |
| 2の出現率 | 100%から4の確率を引く | 90% |
| Undo上限 | 0〜10回、無制限 | 10回 |
| モード | 通常、時間制限、手数制限 | 通常 |
| 制限時間 | 整数10〜3600秒 | 300秒 |
| 制限手数 | 整数1〜100000手 | 1000手 |

設定の編集中は盤面、スコア、手数、乱数、達成状態を変更しません。専用の「この設定で新しいゲーム」で検証し、構築に成功した新しいGameStateだけを採用します。初期枚数等を勝手に丸めたり、サイズ変更時に自動補正したりしません。通常の「新しいゲーム」と結果ポップアップの同ボタンは、編集中の値にかかわらず現在適用中の設定を使用します。

数値の欠落、文字列、NaN、Infinity、小数、不明な項目、範囲外、サイズに対して多すぎる初期枚数を実行時に拒否します。UIの数値入力から受け取る文字列は境界で数値に変換し、空欄は数値0として扱いません。保存対象は適用済み設定です。編集途中の値は保存・復元しません。制限値は選択中のモードの値だけを検証します。モード変更でも、適用時は盤面・スコア・手数・Undoを新規開始し、時間制限は開始待ちに戻します。

## 到達不能の警告

マス数M、出現し得る最大の数字Bとし、到達可能な単一タイルの上限として次を使用します。

```
upper = B × 2^(M−1)
M = N²
B = 2（4が0%のとき）、それ以外は4
```

通常の2/4出現ゲームのマス数と最大タイルの関係は[Das・Paulの研究](https://arxiv.org/abs/1804.07393)で扱われています。以下は本実装の出現制限にも適用するための上限の説明です。

Bより大きい数字は出現せず、同じ数字2個の合体だけで作ります。B×2^M以上のタイルを初めて作るには、その直前に少なくとも2個のB×2^(M−1)以上が必要です。さらに、その2個が初めて存在する前には3個のB×2^(M−2)以上が必要になります。同じ議論を繰り返すとM+1個のB以上のタイルが必要になり、Mマスに収まりません。このため上記より大きい目標は到達不能です。初期配置もB以下だけなので、この条件を回避しません。

例：3×3は4が0%なら上限512、それ以外は1024です。4×4で4が0%の場合でも、目標65536はこの判定では除外しません。上限以下が実際に到達可能か、個別シードで達成できるかは判定しません。難しいという理由や、未証明の推測で禁止しません。

到達不能と証明できる場合は設定適用前から日本語で警告し、目標・サイズ変更の提案を表示します。警告を確認して同じ設定でスコアを目指すこともでき、開始を禁止したり、別の目標へ変更したりしません。

## 初期全マス配置

配置は空きマスの中から抽選するので重複しません。2/4が混在する全マス配置には、隣接する同数字がなく最初から動けないケースがあります。設定画面で事前説明し、実際に手詰まりなら0手・0点のゲームオーバーを表示します。「盤面を見る」で閉じても移動を受け付けません。固定シード6、3×3、9枚、4が50%でこのケースを再現できます。

## シード互換性と表示

乱数アルゴリズム`mulberry32-v1`、ルール版`2048-v1`、抽選順（空きマス→数字）、棄却法、0/100%や空き1マス時の抽選回数は維持します。`random.ts`と`spawn.ts`の変更はなく、4×4の走査順・合体ID発行順も変えません。サイズ・確率・初期枚数が同じなら、同じシードと操作列から同じPositionを再現します。

盤面はページ幅に収め、Nに応じた列数・行数・文字サイズを使います。大きい数字は必要に応じて指数表記にし、各マスのtitleとaria-label、および開閉式の正確な数字一覧に省略しない値を保持します。一覧はタッチでも開け、キーボードではTabで移動できます。数値一覧や設定入力での矢印キーはゲーム移動に使いません。
