# スペシャルタイム

既存の自動スペシャルタイルとは独立して、指定した有効移動の周期ごとに数字の変更権を獲得します。初期値はOFF・10手・最大3回・数字2/4/8/16/32/64/128/256すべてです。間隔は1〜100、最大保有数は1〜10、数字は許可値から重複なしの1種類以上を選択できます。編集中の設定は新規ゲームの適用時だけ反映し、OFFは既存の乱数・移動・Undoの動作を維持します。

## 獲得・消費の不変条件

Position（盤面・スコア・手数・乱数・次ID）は従来どおりUndoの対象です。PlaySession.specialTimeはUndo対象の外に置きます。

- processedEvents：処理済み周期番号の最大値。周期kは手数k×Nで発生します。上限のため付与しなかった周期も処理済みにします。
- granted：実際に付与した権利の累計。
- used：確定した数字変更の累計。
- charges：現在の残数。常に`charges = granted - used`、`0 <= charges <= maxCharges`です。
- `min(processedEvents, maxCharges) <= granted <= processedEvents`、`0 <= used <= granted`を満たします。
- `floor(moveCount / N) <= processedEvents`、`processedEvents * N <= moveCount + undoUsed`です。右辺はこのゲームで成立した前進移動の総数です。

有効移動の既存生成処理を確定した後、`floor(newMoveCount / N) > processedEvents`なら新しい周期を処理します。残数が上限未満のときだけ1回付与し、上限なら付与せずprocessedEventsだけ更新します。無効移動は何も更新しません。各有効移動は手数を1だけ増やすため、新しい周期を飛び越しません。

Undoはこれらを一切巻き戻しません。10手目から9手目へ戻り再び10手目を通っても再取得せず、次の新規周期である20手目では取得できます。上限で見送った権利の遡及付与もありません。表示の残り手数は`(processedEvents + 1) * N - moveCount`とし、Undo後に取得済み周期での付与を約束しません。新規ゲームで全カウンターを0にします。

## 変更確定

変更権があり、期限切れ・手数上限・目標ポップアップ中でなければ開始できます。通常モードの手詰まりは終了ダイアログから修復できます。変更中は通常移動とUndoを禁止し、盤面内のボタンをクリック／タップ／キーボードで選択します。数字ボタン、プレビュー、確定、キャンセルを用意し、同じ数字への変更は確定できません。

確定は純粋関数editSessionTileで1マスだけ変更します。空きマスはnextTileIdを割り当てて1増やし、既存タイルはIDを維持して指数だけ変更します。乱数・手数・スコアは変えず、通常タイルも生成しません。通常の合体ルールをそのまま使います。変更後に目標・手詰まりを再判定し、目標通知の既存優先順位を維持します。

確定時には古いUndo履歴をすべて破棄し、Undo使用数・残り回数は維持します。次の通常移動は変更後のPositionを履歴に積むため、それをUndoすると変更後の盤面へ戻れます。変更前には戻れません。確定後に変更UIを即座に破棄し、二重送信は拒否します。キャンセルは盤面・権利に影響しません。

既存の145ms/120msアニメーション中は開始・確定を禁止します。変更UIそのものにタイマーや追加のアニメーションを設けず、reduced-motionでも同じ操作ができます。新規ゲーム・復元では古いUIを持ち越しません。

## 3モードと既存の自動スペシャル

通常モードは手詰まりでも残る権利で修復できます。時間制限では編集中も時計が進み、期限切れを観測した時点で未確定内容を破棄します。確定直前にも期限を再確認し、締切以降は確定・移動・Undoを禁止します。保存復元・Undoによる締切の延長はありません。

手数制限では上限手の権利獲得を確定してから終了します。終了状態ではその権利を使用できず、既存のUndoで上限未満へ戻った場合だけ使えます。編集は有効移動数や自動スペシャルの周期を進めません。5手ごとに32、10手ごとに権利という併用では、10手目に両方を処理します。

盤面直上の同じカードに、状態表示・変更権残数・開始ボタン・数字選択・プレビュー・確定／キャンセルをまとめます。変更中は表示をコンパクトにし、画面の高さに合わせて盤面を収め、操作欄と盤面の往復スクロールを不要にします。初回の盤面フォーカスも、操作欄を含む領域を画面内へ表示します。適用済みのON/OFFと、「待機中」「変更権あり」「数字を変更中」を常に表示します。変更中は盤面を紫の枠で強調し、開始ボタンは「数字を変更する」と表示します。設定欄でONへ編集しただけの場合は、現在のゲームの表示をOFFのまま維持します。期限切れ・手数上限は「使用終了」と表示します。状態表示には高さの余裕を持たせ、移動ごとの表示更新で盤面が上下しないようにします。

## 保存v4と検証

localStorageの保存キーは変更せず、進行JSONだけv4に更新します。適用済みspecialTime設定、上記4カウンター、game.editEffectsを保存します。編集中の選択・プレビューは保存しません。v1/v2/v3はスペシャルタイムOFFとして復元し、旧スペシャルタイル設定・Undo履歴・bigint・乱数・締切を維持してv4へ移行します。

editEffectsには、edits（確定回数）、lastEditMove（直近の確定手数）、emptyEdits（空きマスへの累計確定回数）、massDelta（編集による盤面質量差分の累計）、potentialDelta（編集によるΣ(value×(power−1))の差分累計）を保存します。差分は負数を含む正規10進文字列として保存し、復元時にbigintへ戻します。Undoでこれらを戻しません。

従来の算術検証を維持し、次の補正を加えます。Mは初期枚数+手数、Sは自動スペシャルの出現回数、Vはその値、Pは盤面のpotentialです。

```
normalMass = boardMass - massDelta - S * V
normalCount = M - S
fourCount = (normalMass - 2 * normalCount) / 2
score = P - 4 * fourCount - S * V * (log2(V) - 1) - potentialDelta
nextTileId = 2 * M + 2 * emptyEdits - occupiedCells + 1
revision = moveCount + 2 * undoUsed + edits
used = edits
history/current moveCount >= lastEditMove
```

最後の条件で、差分が0になる変更を繰り返した場合にも、変更前の古いUndo履歴の混入を拒否します。編集ありの累積得点はpotentialの減少を繰り返すと旧上限を超え得るため、スペシャルタイムONだけ安全整数の最大アクション数を考慮した保守的得点上限を使います。OFFの検証上限は従来どおりです。

不正な型・範囲・権利残数・処理済み周期・編集回数・ID・得点・履歴遷移を拒否します。破損した進行データでも新規ゲームを開始でき、有効なベストは別キーで維持します。保存拒否・容量不足時のメモリ上の継続／現在盤面優先保存も維持します。検証は整合性の確認であり、ブラウザー所有者による意図的な改ざんの認証ではありません。

## ベスト記録

既存のキー・version=1は維持します。スペシャルタイムONだけ条件配列の末尾に`['special-time', interval, maxCharges, sortedAllowedValues]`を追加します。自動スペシャルONの条件とも組み合わせます。許可値の順序はソートして正規化し、同じ集合を同じ条件とみなします。OFFでは編集した間隔・上限・許可値を比較条件に含めず、旧記録をそのまま使います。

## 検証

既存900件を維持し、special-time-core / special-time-persistence / special-time-uiに135件を追加します。周期1/10/100、上限見送り、Undoの重複防止、編集前履歴の破棄、編集後移動Undo、3モード境界、全許可数字と不正設定、空き／占有セル、得点・乱数・ID、v1/v2/v3移行、破損データ、記録分離、保存拒否・容量不足、編集・プレビュー・キャンセル・二重確定・古いUI破棄・reduced-motionを検証します。


## スクロール不要の操作確認

任意のPlaywright環境で`tests/browser/unified-controls.mjs`を実行できます。`PLAYWRIGHT_MODULE`にPlaywrightのモジュールパス、`TEST_URL`に検証対象を指定します（既定はローカル4177番）。アプリの依存関係は追加しません。PC 1280×720、320×568、390×667で、操作欄と盤面が画面内に収まり、開始・最下段マス選択・数字選択・確定の各段階でscrollYが変化しないことを測定します。

## 選択タイルの個別移動

スペシャルタイムを開始した間だけ、マスを選択してスワイプ・矢印キー・方向ボタンでそのタイルを移動できる。スワイプ開始位置でも選択できる。空きを通って端または障害物まで進み、同じ数字は一度だけ合体する。他のタイルは移動しない。成功時に変更権を1回消費して通常操作へ戻る。無効操作は消費しない。数字変更も従来どおり選べる。

通常の手数・乱数・新規生成は進めず、合体時だけ得点を加算する。変更前のUndo履歴を破棄し、その後の通常移動のUndoは個別移動後へ戻る。保存v4の既存editEffectsに変更回数を記録し、質量・ポテンシャルの補正は増やさない。合体によるIDと得点は通常の整合式で検証する。時間切れ・手数上限・権利不足では使用できない。
