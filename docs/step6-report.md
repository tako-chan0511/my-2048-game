## 実装内容・方式

- 移動145ms→合体・出現120msの2段階で描画します。合体タイルは最大1.12倍、新規タイルは0.75倍から通常サイズになります。
- 既存の`moveGame`が返す`motions`・`merges`・`spawned`をそのまま使用します。タイルIDで元の数字・座標と完成タイルを追跡し、1枚の出力を再合体する描画はしません。
- `moveSessionWithResult`で1回のエンジン結果をセッションとともに返します。従来の`moveSession` APIを互換ラッパーとして維持し、スライド・合体・乱数・得点の実装は変更していません。
- ゲーム結果・保存・Undo・目標・終了判定は入力時に確定します。animationend等で結果を再計算しません。
- 確定盤面をアクセシブルなtable/row/cellとして常時保持し、aria-hiddenの表示レイヤーだけを動かします。重複読み上げを防ぎ、正確な数字一覧・フォーカス制御を維持します。
- 位置は盤面サイズ・割合・共通gap変数から算出します。3×3〜10×10を共通処理し、移動はCSS transform、拡大はscale、出現はscale/opacityで描画します。常時JavaScriptで全タイルを再描画するループはありません。
- 最新の1移動だけを描画します。高速入力時に古い演出を中断し、世代番号とタイマー解除で古い完了処理を無効化します。入力待ち行列は設けません。演出タイマーは最大1本です。
- Undo・新規ゲーム・復元・ポップアップ・非表示・コンテナ幅変更では静止した確定盤面へ切り替えます。旧イベントを再生しません。保存形式は変更せず、演出情報も保存しません。
- `prefers-reduced-motion: reduce`では演出レイヤー・演出タイマーを作りません。実行中の設定変更も反映し、CSSでもanimationを無効化します。

詳細は[アニメーション仕様](animations.md)に記載しています。
