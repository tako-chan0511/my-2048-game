# スペシャルモード

設定パネルでON、間隔1〜100手、数字8 / 16 / 32 / 64 / 128 / 256 / 512 / 1024を選択します。初期値はOFF・5手・32、出現方式は通常タイルの置換です。「この設定で新しいゲーム」で適用し、編集中の値は現在のゲームに反映・保存しません。OFFでは間隔と数字を無効化し、4の出現率は独立して編集できます。通常の新規ゲームボタンは適用済みの設定を使います。

## 移動と乱数の順序

1. 従来のスライド・合体を計算します。無効移動はそのまま返し、手数・乱数・ID・履歴を消費しません。
2. 成立後の手数を1増やし、`moveCount > 0 && moveCount % interval === 0`を判定します。
3. 空きマスをインデックス昇順で列挙し、既存の`drawBelow(rng, empty.length)`で位置を抽選します。
4. 通常手は続いて`drawBelow(cell.rng, 100)`で2・4を選択します。確率0%／100%でも従来どおり数字抽選を実施します。スペシャル手は数字抽選を実施せず、位置抽選後の乱数状態で指定値を1枚だけ生成します。
5. 合体得点だけを加算し、生成を含むPositionを確定してから目標・終了条件を判定します。

`drawBelow`は従来のmulberry32-v1と棄却抽選を使用します。1回の抽選が複数のuint32を消費する場合もあり、`randomDraws`は実際の消費数です。空きマス1個でも位置抽選を消費します。空きなしは通常と同じく生成・抽選・ID割当なしです。有効移動は必ず空きを作るため、通常は1枚生成できます。

初期タイルは常に通常の位置→数字の順で生成します。OFFの通常手も従来の順序・生成結果を維持します。同じ設定・シード・入力列は同じPositionになります。

## Undo・3モード

追加の周期カウンターは持ちません。PositionのmoveCountから判定するため、盤面・スコア・乱数・nextTileIdと一緒にUndoでタイミングも戻ります。5手目をUndoし同じ方向へ移動すると同じ位置・IDのスペシャルタイルを再現します。別方向は復元された乱数と、その方向で得られる空きマスから抽選します。Undo使用数は巻き戻しません。

通常モードは目標達成後も続行できます。時間制限は最初の有効移動で開始し、締切以降は移動・Undoを拒否します。Undoと保存復元は締切を延長しません。手数上限ちょうどの生成を確定してから終了し、Undoで再開できます。目標と終了が重なる場合の目標通知優先も従来どおりです。

## 保存形式とベスト互換性

進行の保存キー`my-2048-game:progress:v1`は維持し、JSONのversionを3にします。適用済みの`special: { enabled, interval, value, replacement: 'replace' }`を保存します。OFFでも適用した間隔・数字を保存し、再読み込み時に設定欄へ戻します。デフォルトOFFはメモリ上で旧形式の省略形へ正規化し、従来のGameSettingsとの互換性を保ちます。

v1・v2の進行はOFF・5手・32として復元し、v1の時計補完とv2の締切は維持します。移行成功時に同じキーへv3を書き戻します。不正JSON・未知version・範囲外・不正数字・方式・破損履歴を拒否し、ゲームを新規開始できます。有効な別キーのベストは保持します。bigintは引き続き10進文字列、履歴・ID・乱数・時計の形式と容量不足時の処理も維持します。

保存データの質量・得点検証を拡張します。M=初期枚数+手数、S=ONならfloor(手数/間隔)、OFFなら0、V=スペシャル値、T=盤面合計とすると：

```
normalCount = M - S
normalMass = T - S * V
fourCount = (normalMass - 2 * normalCount) / 2
potential = Σ(value * (power - 1))
score = potential - 4 * fourCount - S * V * (log2(V) - 1)
nextTileId = 2 * M - occupiedCells + 1
```

通常の質量範囲は4の出現率に応じて検証し、スペシャル生成の寄与は得点から除きます。履歴の隣接Positionは実際の移動で再計算し、乱数とIDも一致を確認します。

ベストの保存キー・version=1は変更しません。OFFの条件キーは従来の7要素のまま、ONだけ末尾に`['special', interval, value, 'replace']`を追加します。OFFの間隔・数字は比較条件から除外します。旧記録の書換え・削除は不要です。

## 表示と検証

現在の設定と次回までの手数を表示します。出現時の紫枠・星・通知はMovePresentationから描画し、タイルの永続データには付けません。通常の数値として合体します。追加の演出タイマーは設けず、既存のスライド145ms・合体／出現120msを使います。Undo・新規ゲーム・復元で古い表示を捨て、reduced-motionでは移動アニメーションを作りません。

追加テストは`special-core.spec.ts`、`special-persistence.spec.ts`、`special-ui.spec.ts`、共有fixtureは`special-fixtures.ts`です。既存788件に112件を追加し、合計900件です。周期1・5・100、全許可数字、不正入力、OFFの生成一致、乱数抽選順、Undoの同方向／別方向、3モード、目標と締切／手数上限の境界、v1/v2移行、記録分離、bigint、保存拒否・容量不足・破損、設定の編集／適用分離、演出破棄・reduced-motionを検証します。
